O(1)

Constant work. Example: array index lookup.

O(log n)

Cut the search space each step. Example: binary search.

O(n)

One pass over input. Example: scan an array.

O(n log n)

Split plus linear work per level. Example: efficient sorting.

O(n^2)

All pairs or nested loops. Example: compare every pair.

O(2^n)

Choose or skip each item. Example: all subsets.

O(n!)

All arrangements. Example: all permutations.
